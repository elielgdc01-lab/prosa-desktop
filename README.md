# Prosa para Windows

Voz, câmera e tela compartilhada com quem você gosta.

**Baixar:** [Prosa-Setup.exe](https://github.com/elielgdc01-lab/prosa-desktop/releases/latest/download/Prosa-Setup.exe)

Na primeira vez o Windows pode mostrar "O Windows protegeu o computador", porque o programa ainda não tem assinatura digital.
Clique em **Mais informações** e depois em **Executar assim mesmo**.

Também funciona direto no navegador: https://vemprosa.vercel.app
